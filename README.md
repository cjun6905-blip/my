# IrisGo Proxy

自托管的 IrisGo 账号池与 OpenAI 兼容反代，支持独立账号代理、API Key、流式响应，以及 App 协议 Google 授权（S256 PKCE）。服务器无需安装 IrisGo 桌面客户端。

## 快速开始

1. 安装 Node.js 22 或 24。
2. 在源码目录运行 `node server.js`，无需安装 npm 依赖。
3. 打开启动日志中的面板地址。首次管理员令牌见 `data/admin-token.txt`，也可在受保护的 `data/config.json` 中查看。启动日志不会打印令牌。
4. 使用管理员令牌登录，打开同域名下的 `/irisgo-authorize.html`。
5. 选择出口代理，生成 App 协议授权链接，在 Google 官方页面完成授权。浏览器提示打开 IrisGo 时取消，复制官方回调页完整地址或“Open IrisGo”按钮链接，粘贴回授权页完成导入。
6. 在管理面板创建 API Key。客户端 Base URL 为面板地址加 `/v1`，使用新建的客户端 Key，不是管理员令牌。

授权有效期为 10 分钟；刷新授权页或重启服务后请重新生成。旧 `web:` 链接不再适用于新授权页。既有账号重新授权会更新凭据，但保留其原来的代理绑定。也可在账号池中手动粘贴 Token；不要把凭据提交到 GitHub。

## 账号独立代理与服务器部署

配置、代理槽目录、安全保护和容器运行说明见 [SERVER.md](SERVER.md)。管理面板的 Google 登录与添加上游账号是两个独立功能：前者需要自己的 OAuth 配置，后者使用上述专用授权页。

本机默认只监听回环地址。公网部署应使用 HTTPS 入口，保护管理面板和持久化数据，不要直接暴露数据目录或代理凭据。

## 测试

```sh
node scripts/proxy-routing-test.js
```

测试使用临时数据、模拟账号和本机测试代理，不读取真实账号，也不向 IrisGo 发送聊天请求。真实 Google 授权导入需要用户自行验收。

## 安全与限制

- 仓库仅包含源码，不包含账号 Token、Refresh Token、管理员令牌、客户端 Key、代理订阅或 SSH 私钥。
- 每次全新启动会生成自己的管理凭据；`data/` 必须自行备份并限制访问权限。
- PKCE 校验密钥仅保留在服务内存，不返回浏览器、不写入账号配置，兑换后或过期清理。
- 上游服务、模型和代理的可用性不由本项目保证。登录兼容不意味着能够解决上游认证 503，也不会绕过认证或风控。
- 使用前请确认账号授权及上游服务条款。不要用本项目规避安全限制、转售未获授权的服务或共享他人凭据。
- 本项目不是 IrisGo 官方产品，不会自动跟踪或更新官方登录协议。
